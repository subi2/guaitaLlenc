01 · Start

Getting started
  1. Open guaitaLlenc.html in a modern browser. No installation or connection is needed.
  2. On the start screen choose a size or a template and press Crea el document (Create the document); you can also open a recent .llenc.
  3. Draw, type or drag images and SVG onto the canvas.
  4. Save with Ctrl+S and export with Ctrl+Shift+E.
Privacy: documents, images and packs are processed in your browser. The app only connects to the Internet if you enable GitHub synchronisation.
The browser keeps automatic copies of your work for recovery, but this does not replace the file: save the .llenc often.

The interface and menu labels are in Catalan; this manual gives them in brackets where useful.

04 · Objects

Properties and layers

The right panel shows position, size and rotation (they accept expressions and units, such as 10mm+2cm), fill (colour, linear gradient), stroke, opacity, blend mode, shadow and blur. Copy and paste a style with Ctrl+Alt+C / V.

The Layers tab (Capes) shows the object tree: drag to reorder, and use the eye and padlock to hide or lock. F2 renames.

05 · Text

Text and variable fields

Double-click (or press Enter) to edit. Text boxes grow automatically. You can insert variable fields that update by themselves: {títol} (title), {autor} (author), {data} (date), {pàgina} (page) and {pàgines} (pages), plus your own fields (Insereix → Camp variable).

Built-in typefaces: IBM Plex (Sans, Serif, Mono, Condensed), Inter, Montserrat, Fredoka and Baloo 2; they do not depend on the Internet.

06 · Colour

Colours and styles

Linked colours and text styles are defined in the document (Fitxer → Colors i estils del document; File → Colours and styles of the document): change one and every object that uses it is updated. Fitxer → Paleta del document (File → Document palette) applies complete palettes, including those from packs.

07 · Pages

Pages

A document can have one page or many, each with its own size and background. Ctrl+Shift+N adds a page; PageUp/PageDown move between them. The All view (Totes) shows them together. Guides are created by dragging from the rulers.

08 · Content

Library and packs

The Library (B) holds templates and symbols, searchable by category. One click inserts a symbol as an editable group. Insereix → Els meus (Insert → My items) saves your own templates and symbols.

Packs (.llencpack.json) extend the library: kids (ages 6–16), business (empresa) and architecture and engineering (sections, layers, legends, signage, building services). Load them from Insereix → Paquets de biblioteca (Insert → Library packs), from a file or a web address; they stay in the browser.

Kids mode (Mode infantil, under Visualitza / View) enlarges the interface and shows friendlier typefaces.

10 · Team

Teamwork with GitHub

Work as a team asynchronously on a GitHub repository, with history and authorship.

  1. Fitxer → GitHub → Connexió amb GitHub (File → GitHub → GitHub connection): paste a fine-grained token with read and write permission for Contents on that repository only, and enter user/repository, branch and folder. Test the connection and save.
  2. Sincronitza (Synchronise, Ctrl+Alt+S): the first time it links and uploads the document; afterwards it receives other people's changes and uploads yours.
  3. A colleague can use Obre des de GitHub (Open from GitHub) to download the document.

Each document is a folder with doc.llenc (snapshot) and ops/<editor>.jsonl (each editor's operations). If two people change the same property at the same time, the last change wins; everything else is merged without conflicts.

Version history

It lists versions with author, date and note; it allows preview, comparison of two versions (or one with the current one) and restore. Restoring creates a new change that can be undone and deletes nothing. It also shows how many objects each author last touched.

The cloud icon in the top bar shows the status: grey not linked, green synchronised, yellow with pending changes, red with an error.
The token is only sent to api.github.com. It is not remembered by default: tick «Recorda el token» (Remember the token) only on a trusted computer.

12 · Help

Frequently asked questions
I closed the browser without saving. Can I recover the document?

Yes: the start screen lists the documents saved automatically in this browser. If you have cleared the browser data, you cannot.

Why does the PDF go through the print dialogue?

The PDF is generated by the browser's print function («Save as PDF»), which keeps text and vector graphics. A built-in generator is planned for a later version.

Synchronisation says «Conflicte» (conflict).

Someone uploaded changes while you were synchronising. The app merges again and retries automatically; if it persists, synchronise again.

I cannot see an image from a colleague after synchronising.

Image data travels in the snapshot: wait until your colleague has finished synchronising, then press Synchronise again.
